# Дэвсгэр салгах загвар

Энэ хавтас **хоосон байж болно** — вэб хэвийн ажиллана.

Загвар байхгүй бол цээж зургийн хэрэгсэл нь дүрсийн хүрээний (silhouette)
аргаар ажиллана. Загвар нэмбэл буржгар үс, нимгэн шилний ирмэгийг илүү сайн
барина.

## Суулгах

`u2netp.onnx` файлыг энэ хавтсанд хийнэ:

```
public/models/u2netp.onnx
```

Дараа нь юу ч тохируулах шаардлагагүй — хэрэгсэл өөрөө олж, ашиглаж эхэлнэ.
Ажилтны дэлгэц дээр «Дэвсгэр салгалт: U²-Net загвар» гэж харагдана.

## Аль загварыг сонгох вэ

| | U²-Netp (санал болгох) | U²-Net бүтэн |
| --- | --- | --- |
| Хэмжээ | ~4.7MB | ~176MB |
| Хурд | Хурдан | Удаан |
| Чанар | Хангалттай | Арай сайн |

Дэлгүүрийн дэвсгэр жигд байдаг тул **U²-Netp хангалттай**. Бүтэн хувилбар нь
татах хугацаагаараа хожно.

## Лиценз — чухал

U²-Net нь **Apache 2.0**. Арилжааны хэрэглээнд чөлөөтэй.

Энэ нь санамсаргүй сонголт биш. Дараах өргөн хэрэглэгддэг загварууд нь
**худалдааны хэрэглээнд хориотой** тул дэлгүүр ашиглах эрхгүй:

| Загвар | Лиценз | Арилжаанд |
| --- | --- | --- |
| CodeFormer | S-Lab License 1.0 | ❌ |
| IDM-VTON | CC BY-NC-SA 4.0 | ❌ тусад нь лиценз |

InsightFace-ийн **код** нь MIT — хориотой нь бэлэн сургагдсан **жин**. Энэ
ялгаа амархан алдагддаг.

`test/customer-web.test.ts` дотор эдгээр нэрийг кодоос хайж, олдвол тест
унана. Санамсаргүй нэмэхээс сэргийлсэн түгжээ.

## Яагаад браузерт вэ

Загварыг сервер дээр ажиллуулах саналыг авч үзсэн. Браузерыг сонгосон:

| | Браузер | Python + GPU сервер |
| --- | --- | --- |
| Сарын зардал | 0₮ | ~$100–300 (GPU VPS) |
| Үйлчлүүлэгчийн царай | Төхөөрөмжөөс гардаггүй | Сервер рүү гарна |
| Ажиллагаа | Байхгүй | Дараалал, хадгалалт, хяналт |
| Үр дүн | Ижил загвар | Ижил загвар |

Ижил загвар, ижил үр дүн — тиймээс нэмэлт өртөг төлөх шалтгаангүй.

`onnxruntime-web` нь **загвар байвал л** татагдана: код эхлээд `HEAD` хүсэлтээр
файл байгаа эсэхийг шалгаж, байхгүй бол динамик import хүртэл хүрэхгүй.
